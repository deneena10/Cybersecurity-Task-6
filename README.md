# Task 6: Create a Strong Password and Evaluate Its Strength

## Objective
To understand the characteristics of a strong password by creating passwords with different levels of complexity and evaluating their strength using an online password strength checker.

## Tools Used
- PasswordMeter (https://passwordmeter.com)
- WPS Office / Microsoft Word

## Procedure
1. Created multiple sample passwords with varying complexity.
2. Opened the PasswordMeter website.
3. Tested each password individually.
4. Observed the password strength rating and security feedback.
5. Recorded the estimated time required to crack each password.
6. Compared the results to understand the importance of password length and complexity.

## Key Learnings
- Longer passwords are more secure.
- Using uppercase and lowercase letters, numbers, and special characters increases password strength.
- Avoid using common words, personal information, and dates in passwords.
- Strong passwords provide better protection against brute-force and dictionary attacks.

## Outcome
Successfully evaluated the strength of different passwords and learned best practices for creating secure passwords to improve cybersecurity.
